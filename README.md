# 音の高さの聞き方を測ってみよう（絶対音感と相対音感）体験ページ

授業（知覚・認知心理学特殊Ⅰ 第8回）で，学生が自分のスマホで，絶対音感と相対音感を，約5分で体験するためのページです。Miyazaki & Rakowski (2002) の方法を，授業用に短くしました。

- 回答は，端末の中だけで計算されます（送信も保存もしません）。外部への通信や，ブラウザの保存機能は，使っていません。
- ファイルは `index.html` の1つだけです（そのまま GitHub Pages で公開できます）。
- イヤホンを推奨します。端末の**マナーモードを解除**してください（iPhone では，消音のままだと，音が出ないことがあります）。

## 体験の内容
- **パートA 絶対音感**（12問。約1.5分）：基準の音なしで，1つずつ鳴る音の**音名**を，鍵盤の画面から選びます。12のピッチクラスを1回ずつ，ランダムな順で出題。連続する2音は，ピッチクラスの円で**3ステップ以上**，かつ**1オクターブより大きく**離れます（論文の規則）。範囲は C3〜B6。もう一度は聞けません。偶然の正答率は，約8％（1/12）。
- **パートB 相対音感**（18問。約3分）：画面に，ハ長調の7音の旋律（楽譜）が出ます。そのあと，ある旋律を聞き，**楽譜と，音の関係（相対的な高さ）が，同じか，違うか**を答えます。旋律の前に，その高さの調を示す和音（I–IV–V–I）が鳴ります。聞く旋律は，**移調なし／4半音下／6半音上**（各6問。同じ3問・違う3問）。違う旋律は，1つの音が，1〜2半音ずれます。答えるたびに，正誤が出ます。偶然の正答率は50％。
- **楽譜の下の「ドレミ」表示**は，学生が選べます（楽譜が読みにくい人向け。表示すると，音名がわかるので，論文の条件とは違います）。
- **結果**：パートAの正答数，パートBの移調ごとの正答数。論文の結果（絶対音感の保持者は，移調で成績が下がる／保持者でない人は，移調の影響が小さい）との比較の文章。診断ではありません。

## 論文との違い
| | 論文（Miyazaki & Rakowski 2002） | この体験版 |
|---|---|---|
| 絶対音感テスト | 60音（C2〜B6）。ピアノ音 | 12音（C3〜B6）。ピアノ風の合成音 |
| 判定 | 正答60〜100％＝保持者，50％未満＝保持者でない | 12音に換算：約7問以上／6問未満（目安） |
| 旋律の課題 | 120旋律 × 3セッション＝360試行。調性あり・なし | 18試行（調性ありのみ） |
| 回答 | 6段階の確信度（分析は，同じ／違う） | 同じ／違う |
| 音 | ピアノの音源 | ピアノ風の合成音（Web Audio） |

## 公開の手順（GitHub Pages。コマンドは使いません）
1. GitHub にログインし，「＋」→「New repository」。名前を入れる（例：`APRP`）。**Public** を選び，「Create repository」。
2. 「uploading an existing file」から，このフォルダの中身（`index.html`，`.nojekyll`，`README.md`，`tools`）を，ドラッグして，「Commit changes」。
3. 「Settings」→「Pages」。「Source」＝「Deploy from a branch」，「Branch」＝`main`，フォルダ＝`/ (root)`。「Save」。
4. 数分後，`https://（アカウント名）.github.io/（リポジトリ名）/` で開けます。
5. QRコードは，`tools/make_qr.py`（`pip install "qrcode[pil]"` のあと，`python make_qr.py アドレス`）か，QRコード作成サイトで作ります。

## 動作確認の範囲
- 出題の規則（連続する2音の距離，オクターブの間隔，旋律の範囲・輪郭の反転，各条件の問題数）は，数千回のランダムな生成で，規則どおりであることを確認しました。
- 画面の流れ（パートA → B → 結果 → やり直し）は，模擬のブラウザで確認しました。
- **実際のスマホでの，音の鳴り方（音量・音色・遅れ）と，画面の見た目は，確認できていません**。授業の前に，実機で確認してください。

## 注意
- 授業での体験用で，診断や評価のためのものではありません。試行が少なく，結果は，ばらつきます。
- 低い音（C3付近）は，スマホのスピーカーでは，聞こえにくいことがあります（イヤホンを推奨）。
- このリポジトリには，コードのライセンスを付けていません。

## 音について（ピアノの音）
- このバージョンは，**ピアノの録音（サンプル音源）**を使います。音源は，**FluidR3 GM サウンドフォント**（Frank Wen 作。**Creative Commons Attribution 3.0**）のグランドピアノで，**gleitz/midi-js-soundfonts**（https://github.com/gleitz/midi-js-soundfonts）の変換版から，C2〜C7の61音だけを，HTMLに埋め込みました（mp3。約2 MB）。**公開するときは，この出典の表示を，消さないでください**（ページの最初の画面にも，表示しています）。
- 音源が読み込めない端末では，**自動で，合成音（ピアノ風）に切り替わります**（合成音だけの旧版は，APRP_体験アプリ_合成音版.html）。
- 最初の「パートAを始める」を押すと，音の準備に，数秒かかることがあります（画面に「ピアノの音を準備しています…」と出ます）。
